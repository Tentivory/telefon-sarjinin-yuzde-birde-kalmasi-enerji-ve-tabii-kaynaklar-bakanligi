# telefon-sarjinin-yuzde-birde-kalmasi-enerji-ve-tabii-kaynaklar-bakanligi
Telefon şarjının yüzde birde kalmasını resmi enerji arz krizi, milli batarya güvenliği ihlali ve tabii kaynak israfı sayan; kabloyu boru hattı, prizi kuyu, 'çok az kaldı idare eder' cümlesini kaçak tüketim beyanı ilan eden Bakanlık. Gerçekten çalışır. Yüzde birler artık rezervdir.
